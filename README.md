# Guess the Replication

A minimal retro 8-bit browser game functioning as a behavioral experiment on how scientists and citizens predict study replicability.

## 📂 Architecture
* **`Game/`**: Contains the static HTML/JS frontend hosted on GitHub pages. Includes `dataset.csv` for easy visual inspection.
* **`Study/`**: Contains researcher R scripts to format the data (fetching abstracts dynamically from Crossref) and analyze the results.

## 🚀 Setup & Deployment
1. **Prepare the Data**: Navigate to the `Study/` folder and run `Rscript convert_dataset.R`. This parses the FORRT database, queries Crossref for abstracts, and generates `dataset.json` and `dataset.csv`.
2. **Setup Supabase**: Create a Supabase project and execute this SQL. *(Note: Schema now tracks returning players via `play_count` and `session_id`).*

    ```sql
    CREATE TABLE trials (
        id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
        session_id BIGINT, play_count INT,
        nickname TEXT, career TEXT, round_number INT, 
        ref_o TEXT, ref_r TEXT, journal TEXT, journal_visible BOOLEAN, 
        player_guess TEXT, true_outcome TEXT, correct BOOLEAN, 
        lives_remaining INT, reaction_time INT, tab_switches INT, 
        level TEXT, timestamp TIMESTAMPTZ
    );

    CREATE TABLE scores (
        id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
        session_id BIGINT, play_count INT,
        nickname TEXT, career TEXT, final_score INT, final_level TEXT,
        rounds_played INT, total_time_ms BIGINT, tab_switches INT, timestamp TIMESTAMPTZ
    );
    
    -- Enable public inserts for game logging
    ALTER TABLE trials ENABLE ROW LEVEL SECURITY;
    ALTER TABLE scores ENABLE ROW LEVEL SECURITY;
    CREATE POLICY "Allow insert" ON trials FOR INSERT WITH CHECK (true);
    CREATE POLICY "Allow insert" ON scores FOR INSERT WITH CHECK (true);
    ```
3. **Configure API Keys**: Add Supabase URL and Anon Key in `Game/index.html`.
4. **Deploy using GitHub Actions**: Configure pages deployment to host specifically the `Game/` directory.
