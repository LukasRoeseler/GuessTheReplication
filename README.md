# Guess the Replication

A minimal retro browser game functioning as a behavioral experiment on how scientists and citizens predict study replicability. It is part of the FORRT Open Research Games project. 

## 📂 Architecture
* **`Game/`**: Contains the static HTML/JS frontend hosted on GitHub pages. Includes `dataset.csv` for easy visual inspection.
* **`Study/`**: Contains researcher R scripts to format the data (fetching abstracts dynamically from Crossref) and analyze the results.
