# Guess the Replication

A minimal browser game functioning as a behavioral experiment on how scientists and citizens predict study replicability.

## 📂 Architecture
* **`Game/`**: Contains the static HTML/JS frontend hosted on GitHub pages.
* **`Study/`**: Contains researcher R scripts to format the initial data and analyze the results.

## 🚀 Setup & Deployment
1. **Prepare the Data**: Navigate to the `Study/` folder and run `Rscript convert_dataset.R`. This automatically pulls the latest `flora.csv` from FORRT, formats it, and saves `dataset.json` inside the `Game/` folder.
2. **Setup Supabase**: Create a Supabase project and execute this SQL to create the tracking tables:
    ```sql
    CREATE TABLE trials (
        id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
        nickname TEXT, career TEXT, round_number INT, ref_o TEXT, ref_r TEXT,
        journal TEXT, journal_visible BOOLEAN, player_guess TEXT, true_outcome TEXT,
        correct BOOLEAN, lives_remaining INT, reaction_time INT, level TEXT, timestamp TIMESTAMPTZ
    );
    CREATE TABLE scores (
        id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
        nickname TEXT, career TEXT, final_score INT, final_level TEXT,
        rounds_played INT, timestamp TIMESTAMPTZ
    );
    
    -- Enable public inserts for game logging
    ALTER TABLE trials ENABLE ROW LEVEL SECURITY;
    ALTER TABLE scores ENABLE ROW LEVEL SECURITY;
    CREATE POLICY "Allow insert" ON trials FOR INSERT WITH CHECK (true);
    CREATE POLICY "Allow insert" ON scores FOR INSERT WITH CHECK (true);
    CREATE POLICY "Allow read" ON scores FOR SELECT USING (true);
    ```
3. **Configure API Keys**: Copy your Supabase URL and Anon Key into `SUPABASE_URL` and `SUPABASE_KEY` at the top of the `<script>` tag in `Game/index.html`.
4. **Deploy**: Push the repository to GitHub. Go to Repository Settings -> Pages, and deploy the `Game/` folder from the `main` branch.

## 📊 Analyzing the Data
1. Go to your Supabase dashboard and export the `trials` table as a CSV.
2. Save it inside the `Study/` folder as `trials_data.csv`.
3. Run `Rscript analysis.R` to view summary statistics regarding behavioral prediction accuracy and the experimental manipulation effect.
